# 기업 정보 자동 수집기 (Company Crawler)

기업 이름 목록을 입력하면, 각 회사의 공식 홈페이지를 자동으로 찾아 핵심 정보를 수집하고 CSV 파일로 저장하는 Python 스크립트입니다.

---

## 어떻게 동작하나요?

회사 한 곳을 처리하는 과정은 **5단계 파이프라인**으로 설계되어 있으며,
각 단계는 다음 단계로 넘어가기 위한 **통과 조건**을 가집니다. 조건을 만족하지
못하면 그 자리에서 실패 처리되고 구체적인 사유가 `error` 컬럼에 기록됩니다.

```
companies.txt (회사 이름 목록)
        ↓
① URL 탐색      구글 → (실패 시) 네이버 검색으로 공식 홈페이지 찾기
        ↓        [조건] 차단 도메인이 아닌 URL을 하나 이상 찾아야 통과
② 크롤링        메인 + 회사소개/About/채용 + CEO 인삿말 페이지 수집
        ↓        [조건] 본문 텍스트가 비어 있지 않아야 통과
③ AI 추출       GPT-4o-mini로 JSON 구조화 정보 추출
        ↓        [조건] JSON 파싱 성공해야 통과
④ 검증          3중 검증으로 "정말 그 회사 페이지인지" 확인
        ↓        [조건] AI 매칭 + 본문 회사명 + 추출 내용 모두 통과
⑤ 저장          output/results.csv 에 한 줄씩 즉시 append
```

---

## 수집하는 정보

| 항목 | 설명 |
|------|------|
| `company_name` | 회사명 |
| `website_url` | 공식 홈페이지 주소 |
| `business_description` | 주요 사업 내용 (2~3문장) |
| `main_products_services` | 주요 제품 / 서비스 목록 |
| `talent_values` | 인재상 |
| `ceo_message` | CEO 인삿말 요약 |
| `crawl_success` | 수집 성공 여부 (True/False) |
| `error` | 실패 시 오류 메시지 |

## 프로젝트 구조

```
company-crawler/
├── main.py           # 메인 스크립트
├── companies.txt     # 크롤링할 회사 목록 (784개)
```

## 설치 및 실행

### 1. 패키지 설치

```bash
pip install -r requirements.txt
```

### 2. API 키 설정

`.env` 파일을 만들고 OpenAI API 키를 입력합니다.

```
OPENAI_API_KEY=sk-...
```

### 3. 회사 목록 준비

`companies.txt`에 회사 이름을 한 줄에 하나씩 입력합니다.

```
삼성전자
카카오
네이버
```

### 4. 실행

```bash
python main.py
```

실행하면 아래처럼 진행 상황이 출력됩니다.

```
총 784개 회사 처리 시작

[1/784] CJ ENM 처리 중...
  → URL: https://www.cjenm.com
  → 완료
[2/784] CJ대한통운 처리 중...
  ...

완료! 결과 저장: output/results.csv
성공: 720/784
```

## 주요 동작 설명

### ① URL 탐색 방식
1. **Google 검색** - `{회사명} 공식사이트`, `{회사명} 홈페이지` 키워드로 검색 (상위 5개)
2. **네이버 검색 (Fallback)** - Google 실패 시 네이버 검색 결과 HTML을 파싱해 첫 링크 사용
3. **차단 도메인 제외** - 공식 홈페이지가 아닌데 검색 상위에 자주 잡히는 도메인은 자동 제외
   - 검색/SNS/백과: 네이버 블로그·카페, LinkedIn, 인스타그램, 나무위키, 위키백과 등
   - 채용 포털: 잡코리아, 사람인, 원티드, 잡플래닛, 인크루트, 게임잡 등
   - 기업정보·신용·공공 포털: 나이스평가정보, 크레딧뱅크, 국세청, 공공데이터포털 등
4. 찾은 URL은 **도메인 루트**(`scheme://netloc`)로 정규화해 사용

### ② 크롤링 방식
- 메인 홈페이지를 받은 뒤, 링크 텍스트/href에서 키워드를 찾아 하위 페이지를 추가 수집
  - 회사소개 계열: `about`, `회사소개`, `company`, `채용`, `인재`, `culture`
  - CEO 계열: `ceo`, `message`, `대표이사`, `인삿말`
- 응답을 **bytes로 파싱**해 meta charset을 자동 감지 (한글 깨짐 방지)
- `script`, `style`, `header`, `footer`, `nav` 등 불필요한 요소는 제거 후 공백 정규화
- 본문은 최대 **4,500자**까지만 AI에 전달

### ③ AI 정보 추출
- 수집된 텍스트를 **GPT-4o-mini** (`temperature=0`)에 전달
- 미리 정의된 JSON 형식으로 구조화된 정보 추출, 코드펜스(```json) 자동 제거
- 정보가 없는 항목은 `null`로 표시 (`"null"`/`"none"`/`""` 문자열도 실제 `None`으로 보정)

### ④ 검증 (3중 체크)
AI가 정보를 뽑았더라도, 엉뚱한 회사·포털 페이지를 긁었을 수 있으므로 세 가지를 모두 통과해야 성공으로 인정합니다.

1. **AI 매칭 판정** (`is_company_match`) - 프롬프트에서 텍스트가 채용 포털/타사 내용이면 `false`로 응답하도록 지시. `false`면 실패.
2. **본문 회사명 확인** (`name_appears_in_text`) - 법인 접미사(`(주)`, `주식회사` 등)·공백 제거 후 본문에 회사명이 등장하는지 확인. 풀네임이 없으면 앞 2글자(브랜드명)라도 있으면 통과.
3. **추출 내용 확인** - `business_description` 과 `main_products_services` 가 모두 비어 있으면 실패(빈/JS 렌더링 페이지 가능성).

### ⑤ 저장 방식
- 회사 한 곳 처리가 끝날 때마다 결과를 `output/results.csv` 에 **한 줄씩 즉시 append** (도중에 중단돼도 진행분 보존)
- 인코딩은 `utf-8-sig` (엑셀에서 한글 정상 표시)
- `main_products_services` 리스트는 `|` 로 join 해 한 칸에 저장
- 회사 사이에 **2초 대기**(`DELAY_BETWEEN_COMPANIES`)로 요청 속도 조절

## 실패 사유(`error`) 종류

성공하지 못한 회사는 `crawl_success=False` 와 함께 단계별 사유가 기록됩니다.

| 단계 | error 메시지 예시 |
|------|------------------|
| ① URL 탐색 | `URL 탐색 실패: 검색 결과에서 공식 사이트를 찾지 못함` |
| ② 크롤링 | `접속 실패(...)`, `빈 페이지(본문 텍스트 없음, JS 렌더링 가능성)` |
| ③ AI 추출 | `JSON 파싱 실패: ...`, `OpenAI 오류: ...` |
| ④ 검증 | `이름 매칭 실패: ...`, `이름 미확인: ...`, `내용 없음: ...` |
